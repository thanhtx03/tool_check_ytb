📌 Cách ghim Extension
1. Bấm icon Mảnh ghép (🧩) trên góc phải Chrome
2. Tìm YT Channel Checker
3. Bấm icon Ghim 📌 để giữ extension luôn hiển thị

🔑 Cài đặt YouTube API Key

1
Truy cập Google Cloud Console Mở Console →
2
Tạo project mới → Enable "YouTube Data API v3"
3
Tạo API Key trong mục Credentials → Copy
4
Dán API Key vào đây (miễn phí 10.000 req/ngày)
Chưa có API Key.
